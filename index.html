🔎 What is this Project?

This unique project is the first-ever effort to create a simulation of core Roblox features—such as movement, world interaction, and building blocks—using only the visual programming language of PenguinMod (or TurboWarp).

This demonstrates the incredible possibilities within the Scratch ecosystem!

🚀 Featured Highlights

  • Platform: Built entirely with PenguinMod/TurboWarp blocks.
  • Focus: Simulating a 3D-like experience using 2D rendering techniques.
  • Current Highlights:
    • ✅ Realistic character movement and camera control.
    • ✅ Dynamic block placement system.
